# 固定費（kakei）

毎月・毎年の固定費と、その支払い方法を管理する iPhone アプリです。
「どのサービスをどのカードで払っていて、そのカードはどの銀行から引き落とされるか」をまとめて確認できます。

## できること

- **固定費の登録**：カテゴリー（電気・ガス・通信費など）、サービス名（例：妻の携帯通信費）、金額、周期（毎月〜毎年）、支払日
- **支払い方法**：銀行引き落とし（口座を選択）／クレジットカード（カードを選択）／振込（振込先を記入）／その他
- **カードと引き落とし口座の紐付け**：カードごとに引き落とし口座・締め日・引き落とし日を登録
- **支払い方法別の集計**：口座ごとに「直接引き落とされる固定費」と「その口座から落ちるカードの固定費」を月額換算で表示
- **カテゴリーの編集**：追加・名前とアイコンの変更・並べ替え・削除

データは端末内（SwiftData）にのみ保存し、外部には送信しません。

## 動作環境

- iOS 17 以降
- ビルドには Mac と Xcode 16 以降が必要

## iPhone に入れる手順

1. このリポジトリを Mac にクローンし、`Kakei.xcodeproj` を Xcode で開く
2. 左のプロジェクト一覧で「Kakei」ターゲット →「Signing & Capabilities」を開き、Team に自分の Apple ID を設定する
   （Bundle Identifier がほかと重複してエラーになる場合は、`com.takusaka-arch.kakei` を任意の名前に変更）
3. iPhone を Mac につないで実行先に選び、▶︎（Run）を押す
4. 初回は iPhone の「設定 → 一般 → VPN とデバイス管理」で開発元を信頼する
   （iOS 16 以降は「設定 → プライバシーとセキュリティ → デベロッパモード」をオンにする必要もあります）

無料の Apple ID で入れたアプリは 7 日で起動できなくなるため、その場合は手順 3 をやり直してください。
Apple Developer Program（有料）に登録すると、有効期間は 1 年になります。

## 構成

```
Kakei/
├── KakeiApp.swift          アプリの入口（SwiftData のコンテナ設定）
├── Models/                 データモデル
│   ├── FixedCost.swift       固定費
│   ├── ExpenseCategory.swift カテゴリー
│   ├── CreditCard.swift      クレジットカード（→ 引き落とし口座）
│   ├── BankAccount.swift     銀行口座
│   └── Enums.swift           支払い方法・周期・口座種別
├── Views/                  画面
└── Support/                表示用の補助・初期データ
```
