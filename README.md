# 固定費（kakei）

毎月・毎年の固定費と、その支払い方法を管理する iPhone 向けの Web アプリです。
「どのサービスをどのカードで払っていて、そのカードはどの銀行から引き落とされるか」をまとめて確認できます。

Mac がなくても、Windows と iPhone だけで無料で使えます。

## できること

- **固定費の登録**：カテゴリー（電気・ガス・通信費など）、サービス名（例：妻の携帯通信費）、金額、周期（毎月〜毎年）、支払日
- **支払い方法**：銀行引き落とし（口座を選択）／クレジットカード（カードを選択）／振込（振込先を記入）／その他
- **カードと引き落とし口座の紐付け**：カードごとに引き落とし口座・締め日・引き落とし日を登録
- **支払い方法別の集計**：口座ごとに「直接引き落とされる固定費」と「その口座から落ちるカードの固定費」を月額換算で表示
- **カテゴリーの編集**：追加・名前とアイコンの変更・並べ替え・削除
- **バックアップ**：データを JSON ファイルに書き出し・読み込み

データは iPhone のブラウザの中（localStorage）にだけ保存され、外部には送信されません。
一度開けば、オフラインでも動きます。

## 公開のしかた（最初の1回だけ）

1. GitHub でこのリポジトリを開き、上部の **Settings** →左メニューの **Pages** を開く
2. 「Build and deployment」の **Source** を **Deploy from a branch** にする
3. **Branch** で `claude/project-thread-xw93bd` と `/ (root)` を選んで **Save**
4. 1〜2分待つと、同じ画面の上部に公開URL（`https://takusaka-arch.github.io/kakei/`）が表示される

## iPhone のホーム画面に追加する

1. iPhone の **Safari** で公開URLを開く
2. 画面下の共有ボタン（□に↑）をタップ
3. **ホーム画面に追加** を選んで **追加**
4. ホーム画面の「固定費」アイコンから起動すると、普通のアプリのように全画面で使えます

> ホーム画面から開いたアプリと、Safari で開いたページは、データが別々に保存されます。
> いつもホーム画面のアイコンから開いてください。

## データのバックアップ

「設定」タブ →「データを書き出す」で JSON ファイルを保存できます（ファイルアプリや iCloud Drive に保存）。
機種変更のときは、新しい iPhone で「データを読み込む」からそのファイルを選ぶと元に戻せます。

## アプリを更新したとき

`sw.js` の `VERSION` を上げてから push すると、次に開いたときに新しい版に切り替わります。

## ファイル構成

```
index.html             画面の枠（ヘッダー・タブバー）
app.js                 データの保存と、4つのタブ・編集画面
style.css              見た目（ライト／ダークモード対応）
manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
sw.js                  オフライン対応（Service Worker）
icons/                 アプリアイコン
```

パソコンで試すときは、このフォルダで `python -m http.server` を実行して http://localhost:8000 を開きます。
